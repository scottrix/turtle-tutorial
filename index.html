Turtle OS

Writing a 64-bit UEFI Operating System in ANSI C
A from-scratch tutorial on booting a freestanding C kernel via UEFI, setting up the GDT, driving a framebuffer console, and printing your first message — with no dependencies beyond GCC, GNU ld, and QEMU.

This tutorial walks through building a bootable 64-bit x86_64 operating system from nothing. We use the UEFI firmware interface (not the legacy BIOS int 0x10 world), write our own EFI type definitions instead of relying on gnu-efi, and end up with a kernel that boots in QEMU and prints to both a graphical framebuffer and a serial port.

The style follows the tradition of books like MMURTl v1.0 and Linux from Scratch: every line of code is shown and explained. Nothing is hidden behind a framework or a library you haven't read.

What you need to know

  • ANSI C — we use C11, freestanding, no standard library
  • x86 assembly basics — registers, instructions, what a stack frame is
  • How to use a terminal and a text editor

You do not need to know UEFI, the 64-bit GDT, paging, or anything about boot protocols. We explain each of these as we encounter them.
